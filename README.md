# DeviceGuard

כלי לניהול הגבלות במחשב Windows (WPF, .NET 8): חסימת תוכנות, הגדרות, התקנות, USB, רשת, סוגי קבצים ועוד – מוגן בקוד, עם שירות הגנה שרץ כ-SYSTEM.

## בנייה

* **GitHub Actions** (מומלץ): כל push ל-`main` בונה ומעלה את `DeviceGuard.exe` כ-Artifact. Release טיוטה נוצר רק בתגית `v*` או בהרצה ידנית עם `release=true`.
* **מקומית**: Windows + .NET 8 SDK, להריץ `build.cmd`. התוצר: `out\DeviceGuard.exe`.

קובץ אחד בלבד. כשלוחצים "החל שינויים" התוכנה מעתיקה את עצמה ל-`C:\ProgramData\DeviceGuard\DeviceGuardWatch.exe` ומתקינה ממנו את השירות והשער (אין יותר `Gate.exe` נפרד).

## מבנה

| קובץ | תפקיד |
|---|---|
| `Program.cs` | נקודת כניסה, שירות ההגנה, שרת ה-Pipe, ניטור תהליכים, תזמון |
| `Enforcer.cs` | החלה וביטול של כל החסימות (IFEO, מדיניות רישום, ACL, חומת אש, USB, שירות) |
| `GateMode.cs` | "השער": חלון הקוד שמופיע כשמפעילים תוכנה חסומה |
| `Config.cs` | ההגדרות, שמירה/טעינה עמידה, גיבוב קודים |
| `MainWin.cs`, `Theme.cs`, `Logo.cs` | הממשק |
| `Native.cs`, `UserSession.cs` | פונקציות מערכת |
| `Alerts.cs` | יומן אירועים והתראות |

## מודל האבטחה והמגבלות

* ההגנה מיועדת למשתמש **שאינו מנהל**. מי שיש לו הרשאות מנהל (או גישה פיזית: Safe Mode, WinRE, כלי SYSTEM) יכול לעקוף כל חסימה. ההגנות כאן מקשות ומתעדות, אך אינן חסינות.
* חסימת קבצים לפי סיומת פועלת רק על כוננים NTFS/ReFS, ולפי סיומת בלבד (שינוי סיומת של קובץ חדש עוקף).
* השער לא ממתין לסיום התוכנה שהוא מפעיל (קוד היציאה של התוכנה לא מועבר חזרה להורה).
* חיבור לאינטרנט ללא סינון מסוכן – מומלץ להשתמש בסינון חיצוני ולא להסתמך על התוכנה בלבד.

## התראות

בחלון "הגנה מתקדמת" אפשר להזין כתובת Webhook (למשל `https://ntfy.sh/<נושא>`). כל ניסיון עקיפה (קוד שגוי חוזר, שחזור חסימה שנמחקה, עצירת שירות) נשלח אליה (בהגבלת קצב), ונרשם גם ביומן המקומי `C:\ProgramData\DeviceGuard\var\events.log`.

## רשימת בדיקה אחרי בנייה (מומלץ על מכונה וירטואלית)

1. התקנה ראשונה: הגדרת קוד, "החל שינויים" – השירות מותקן ורץ (`sc query DeviceGuard`).
2. חסימת תוכנה בקוד (למשל Notepad): פתיחה מבקשת קוד; קוד נכון פותח; הפעלה חוזרת מבקשת שוב.
3. חסימה בקוד של **דפדפן** (Chrome/Edge): קוד נדרש פעם אחת בלבד (תהליכי הבן עוברים).
4. חסימה גמורה של PowerShell, ואז "החל שינויים" נוסף (לא נתקע), ושחרור USB / שינויי רשת עדיין עובדים.
5. פתיחה זמנית (30 דק׳): תמונות/שירים נפתחים וחוזרים להיחסם לבד בסוף, גם אחרי סגירת התוכנה.
6. תזמון: הגדרת חלון קצר, בדיקה שהחסימות נפתחות/נסגרות לבד.
7. USB ברשימה לבנה: רק הכונן שנבחר (לפי מספר סידורי) עובד, כונן אחר מאותו דגם נחסם. **בדיקה חשובה** – מדיניות `AllowInstanceIDs` + `AllowDenyLayered` נבדקה רק מתיעוד.
8. עדכון גרסה: בניית גרסה חדשה והפעלתה על מחשב עם הגרסה הישנה – השירות מתעדכן אוטומטית, והשמירה לא נכשלת.
9. הסרת התוכנה מהחלון: השירות, השער, מפתחות Safe Mode וכללי החומה נעלמים.
